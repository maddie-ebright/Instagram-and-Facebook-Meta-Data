# Social Media Analytics Report
### Instagram & Facebook Meta Business Suite Analysis

## Project Overview

This project demonstrates my ability to analyze social media performance data from Meta Business Suite and translate analytics into meaningful business insights.

Rather than simply reporting numbers, I focused on explaining what each metric actually represents, identifying misleading statistics, interpreting trends over time, and presenting the results in language that non-technical stakeholders can easily understand.

The original project was completed using organizational Meta analytics data. Because the data belongs to the organization and contains internal performance information, this repository includes only a **sanitized sample report** that demonstrates the methodology without exposing confidential information.

---

## Project Objectives

- Analyze Instagram and Facebook performance metrics
- Interpret engagement and audience behavior
- Explain Meta's reporting methodology
- Identify meaningful trends over time
- Produce a report suitable for management and decision makers

## What Was Analyzed

The report includes analysis of metrics such as:

- Views / Impressions
- Reach
- Profile Visits
- Link Clicks
- Content Interactions
- Follower Growth
- Time-series trends
- Comparison-period analysis

One major focus of the project was correctly interpreting Meta's percentage calculations and distinguishing between genuine performance changes and percentages that result from insufficient comparison data.
